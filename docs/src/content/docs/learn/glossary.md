- **Agent**: program on your computer that carries out the model's requests with tools (Claude Code)
- **Clone**: download a repo to your computer, with its history
- **Commit**: a saved version of the project, with a message
- **Environment**: the Python version and packages for one project (managed by uv)
- **MCP / connector**: a tool that lets the agent reach outside services
- **Model**: the AI in the cloud that plans and writes code (Claude)
- **Package**: a reusable piece of Python code (e.g. pandas, matplotlib)
- **Prompt**: what you ask the agent, in plain language
- **Push**: upload your commits to GitHub
- **Repository (repo)**: project folder with full history
- **Skill**: a written SOP the agent loads when a task needs it
- **Template**: a ready-made starting repo
- **Terminal**: text window where you type commands
- **Tool**: an action the agent can take (read, write, run, search)
