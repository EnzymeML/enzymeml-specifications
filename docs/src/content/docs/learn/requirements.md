## Computer
- Windows or macOS
- Internet access
- A few GB of free disk space
- Rights to install software
  - The real blocker on university-managed lab PCs
  - uv and Claude Code install into your user folder (no admin rights), but IT policy may still block them
  - → ask IT first if your PC is managed

## Accounts and cost
- GitHub account: free, including private repositories
- Claude: needs a paid plan (or a university / institute contract)

## Permission to use AI with your data
- University AI policy / contract
- Industry projects: NDAs may forbid sending data to a cloud model

## Checklist
- [ ] Can install software (or IT has approved it)
- [ ] Have / will create a GitHub account
- [ ] Have access to a paid Claude plan
- [ ] Allowed to use AI with this project's data
