## Who this is for
- Wet-lab scientists in catalysis / biocatalysis
- Currently analyse data in Excel and Origin Pro
- No programming background needed

## Why bother?

### The familiar pain
- 40 GC runs → copy-paste into Excel → formulas → Origin plot
- Next batch arrives → do it all again by hand
- Six months later: which file, which formula, which baseline?

### The same task, agent-assisted
- One sentence: "Plot conversion, selectivity and TOF for all runs from October"
- The agent writes the Python, runs it, and fixes its own errors
- The next batch: the same sentence re-runs everything

### What you gain
- Reproducible: delete the results, re-run, get identical figures
- Traceable: every number → script → raw file
- Fast: minutes instead of an afternoon of copy-paste
- Shareable: a collaborator gets the whole analysis, not just the figure

### What you still do
- Decide what to analyse
- Check the chemistry (units, plausibility, missing peaks)
- Approve what the agent does

### Open questions
- Which concrete before/after example to show (GC conversion? kinetics fit?)
- Screenshot or short video of the agent at work?

## What you get
- More efficient analysis and better-quality scientific insight: the agent writes and runs the Python, you judge the science
- Re-analysable: one sentence re-runs the whole analysis when the next batch of data arrives
- Traceable: every number in a figure leads back to a raw file and a script
- Shareable: collaborators get the complete analysis, not just the figure
